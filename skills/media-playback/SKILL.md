# 本地文件展示（Flowship 对话里直接预览 / 播放）

Flowship 的对话界面能把回复里的本机音视频路径渲染成可点击的播放入口：点开进悬浮播放器，支持波形、对比组、字幕、逐帧。
**只有写成下面这种形状，用户才点得开**。

图片、文档、网页等其它文件**同样适用下面的核心规则**（完整绝对路径、行内代码、一个文件一个反引号），点开是文件预览、没有播放器；
下面的时间段、成组对比、支持格式、播放器相关的说明只对音视频有意义。

## 核心规则

**每个要展示的文件都写完整绝对路径，放在行内代码里**（一个文件一个反引号，里面只放路径）。

- 不要只写文件名——没有目录的文件名不会变成入口，用户点不开。
- 不要为了展示去 `open` / `open -R` 弹 Finder 或系统播放器：那只是在用户的桌面上弹窗口，对话里没有任何可点的东西。
- 一次要给多个文件时，**每个文件都要写完整路径**；不要「先给一个目录，再列一串文件名」。

## 正确写法

- 单个文件：`/Users/xxx/out/final.mp4`
- 多个文件（每个都写完整路径）：`/Users/xxx/out/v1.mp3`、`/Users/xxx/out/v2.mp3`、`/Users/xxx/out/v3.mp3`
- 指定时间段（W3C 时间片段，单位秒，可带小数；点开从起点播，到止点暂停）：`/Users/xxx/out/a.mp4#t=12.4,15`
- 只给起点：`/Users/xxx/out/a.mp4#t=12.4`
- markdown 链接也行，**链接目标只认绝对路径**：[成片](/Users/xxx/out/final.mp4)
- 行内代码里**一律写绝对路径**；相对路径只有文件恰好在任务工作目录下才解析得对，不要用。

### 对比与成组

同一条回复里的多个音视频自动成组，用户可用数字键 1–9 在它们之间切换对比；回复定稿后末尾会自动出媒体卡片，**不用再贴一遍**。
要让用户对比版本，就把它们放进同一条回复里。

## 支持的格式

<!-- media-exts:start -->
mp4 m4v mov webm mp3 m4a aac wav flac ogg opus
<!-- media-exts:end -->

- 文件必须已经写入磁盘。
- 给用户看的视频用 **H.264 + AAC 的 mp4**。
- mkv / avi 不会变成播放器；HEVC（H.265）浏览器播不了——请用户点播放器里的「系统播放器打开」。**不要声称这些能在对话里直接播。**

## 常见错误

下面这些都**不会**变成播放入口：

- 只写文件名：`final.mp4`
- 先给目录、再列一串文件名（每一个文件名都不认）：输出在 `/Users/xxx/out/`，文件有 `v1.mp3`、`v2.mp3`
- 波浪号开头：`~/Movies/a.mp4`
- 链接目标写相对路径：[成片](out/final.mp4)
- 放进围栏代码块里的路径（围栏里的内容不会渲染成入口）
- 图片语法、`<video>` 标签
- http(s) 链接：`https://example.com/a.mp4`
- 把时间段占位原样留着：`#t=起,止`

其它注意：

- 文件名里避开 `#` 和单引号（`#` 会被当成时间片段的开头）。
- 只在需要展示时才引用，不要把一堆中间产物都贴出来。
